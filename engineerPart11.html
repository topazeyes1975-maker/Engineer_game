Level 11: C++ Source File Architecture

The C++ Transition: Welcome to the C++ coding phase! Just like physical hardware, source code requires strict structural layout. Review the core sections below, then assemble the scrambled code blocks into their proper top-to-bottom sequence to compile the program.

1. Preprocessing Directives

Must be at the very top. Uses #include and #define for libraries and constant definitions.

2. Function Declarations

Lists function signatures before full definition so the compiler knows argument and return types.

3. Variable Initialization

Allocates program-wide state variables, global counters, and data structures.

4. Main Function & Logic

The mandatory entry point (`main()`) that coordinates execution flow and core processing loops.
